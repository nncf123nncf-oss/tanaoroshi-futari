# 年末棚卸しの二人合算

年末の在庫棚卸しを、2人で売り場と倉庫に分かれて数える小さなお店向けのWebページ（HTML1枚）。

- 1台で棚リスト（棚ごとに品目を1行1つ・単価は任意）を作り、「棚リストのコード」を相手に送ると、同じリストで数え始められる
- 各自の端末で品目ごとに数を入れ、棚ごとに「数え終わった」を付ける
- 「結果コード」をLINEなどで送り合うと合算される。2人とも数えた棚は、どちらの数を使うか選ぶまで合計に入らない（要確認）
- 合算結果（品目・合計数・単価・金額・総額・まだ数えていない棚）をコピーできる

登録・ログインなし。数と棚リストは、その端末のブラウザ（localStorage）にだけ保存し、外部には送らない。
